Digitos activity module for Moodle 3.9+

Simple activity module that displays "Digitos" and a checkbox for completion.

Installation:
1. Copy folder 'digitos' to 'mod' directory in your Moodle installation.
2. Visit Site administration > Notifications to install.
3. Add Digitos activity to a course.

If not detected, ensure:
- Folder name is 'digitos' and placed in 'mod'.
- File 'version.php' exists and correct.
- File 'lib.php' exists and correct.
- File 'db/install.xml' exists and correct.
- File 'lang/en/digitos.php' exists and correct.
- Clear cache if needed.
